# Fontes locais (opcional)

Se preferirem não depender do Google Fonts (CDN), baixem os arquivos .woff2 de:
- Baloo 2 (pesos 500/600/700/800)
- Nunito (pesos 600/700/800/900, regular e itálico)
- Caveat (pesos 600/700)
- Kalam (pesos 400/700)

E troquem o <link> do Google Fonts no <head> do index.html por @font-face apontando pra esses arquivos aqui dentro.
